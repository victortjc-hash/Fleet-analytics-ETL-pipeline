# Fleet-analytics-ETL-pipeline






The dashboard visualizes fleet operational KPIs from curated Parquet data generated by AWS Glue. It shows vehicle utilization, speeding behavior, low-fuel risk, average speed, and daily activity trends using Athena and QuickSight.


What I built: 
Generated fleet GPS CSV data
→ Uploaded raw CSV to S3
→ Used Glue Crawler to detect schema
→ Created Glue Data Catalog table
→ Queried raw data with Athena
→ Ran Glue ETL job to clean/transform data
→ Wrote curated Parquet files to S3
→ Crawled curated Parquet data
→ Queried curated data with Athena
→ Built QuickSight dashboard
